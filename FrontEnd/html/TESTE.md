## 🎨 Efeitos Especiais para Observar

### Hover Effects (Passe o mouse sobre):
1. **Redes Sociais** - Efeito de onda + elevação + zoom do ícone
2. **Cards de Habilidades** - Elevação 3D + linha no topo + shadow colorido
3. **Cards de Projetos** - Overlay gradiente + borda colorida + elevação
4. **Botões** - Efeito ripple + elevação + shadow
5. **Back to Top** - Glow effect + mudança de cor
6. **Links do Menu** - Background laranja + arredondamento

### Scroll Effects (Role a página):
1. **Header** - Muda para glassmorphism
2. **Elementos** - Aparecem com ScrollReveal
3. **Contadores** - Animam quando aparecem na tela
4. **Back to Top** - Aparece após 350px

### Animações Contínuas:
1. **Digitação** - Troca de profissão a cada 2s
2. **Partículas** - Flutuam do fundo para o topo (15-22s cada)
3. **Glow Effect** - Se move pela tela (30s)
4. **Gradiente Home** - Flutua suavemente (20s)

## 🐛 Possíveis Ajustes

Se algo não estiver funcionando:

1. **Limpe o cache do navegador** (Ctrl+Shift+Del)
2. **Verifique o console** (F12) para erros
3. **Certifique-se** de que todos os arquivos CSS estão carregando
4. **Teste em modo incógnito** para descartar problemas de cache
